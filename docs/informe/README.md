# Carpeta del informe técnico

Material de apoyo para el informe técnico de residencia profesional (proyecto CONTATECK, TEC CAPITAL GROUP). Todo se generó a partir del repositorio y de la base de datos reales; nada está inventado.

| Archivo | Para qué sirve |
|---|---|
| `Matriz-Cronograma-vs-Plataforma.md` | Cada actividad del cronograma contra lo que existe en la plataforma, con evidencia, estado y qué falta |
| `diagramas/01-Diagrama-Entidad-Relacion.md` | Base de datos: 25 tablas y sus relaciones (Mermaid) |
| `diagramas/02-Arquitectura-y-Seguridad.md` | Arquitectura general, capas de seguridad y despliegue |
| `diagramas/03-Flujos-de-Proceso.md` | Factura → cobro, venta con revisión, contabilidad electrónica, cierre de periodo, alta de personas |
| `diagramas/04-Matriz-de-Roles-y-Permisos.md` | Qué puede hacer cada rol |
| `Guia-de-Instalacion-y-Operacion.md` | Cómo instalar, probar y operar el sistema, y qué hacer si algo falla |
| `../work-orders/` | Una orden de trabajo por cada cambio (qué se hizo, cómo se comprobó y qué quedó sin verificar) |
| `../work-orders/Reporte-Prueba-Completa-Modulos-2026-11-13.md` | Prueba de todos los módulos con 3 roles (13-nov y 25-nov-2026) |

Los diagramas son de texto (Mermaid): se ven en GitHub y en VS Code, y se exportan como imagen en https://mermaid.live para pegarlos en el documento.
